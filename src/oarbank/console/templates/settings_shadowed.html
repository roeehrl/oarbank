Shadowed values

Values set at the fleet, a group or a node that change no node's effective value: set under a lock (ignored while it holds), the same as what that scope inherits, or with no effect (another scope's value applies). A value equal to the inherited one is still a choice: nothing here is reset unless you reset it.
