Agent

Each node updates its own oarbank-agent through oarbankd: it downloads the build assigned to its platform, checks it, installs it beside the running one, lets its running jobs finish and restarts on it. A build that fails to start, or is not confirmed within 10 minutes, is rolled back on that node automatically. No ssh.
