Groups

A group gives its members settings that differ from the fleet's: laptops' battery and presence rules, a canary cohort, a lab's caps. Membership comes from each node's facts and labels (and any node you list), evaluated whenever settings are resolved, so a node that changes moves at once. Where groups set the same setting, the higher-ranked group wins; a node's own value beats every group unless a group or the fleet locks it. Set a group's values on its page. Bulk changes sets values or labels on many nodes at once.

Labels

Short words on a node that groups select on. Set them on a node's Settings page or on Bulk changes; labels "from facts" (laptop: the node has a battery) come from what the node reports. A group that locks a safety value should select on your own labels, listed members or the OS, which a node cannot claim for itself.
