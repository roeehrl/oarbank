Export and import

Export

A scope's settings as a YAML file: the values set there (a lock as !locked), and for the fleet also its groups, node labels and host tool definitions. Secrets are listed as fingerprints only, never their values.

Or: oarbank settings export --scope fleet > fleet.yml

Import

Upload or paste an export. The preview lists every difference (values, locks, groups, labels, tools) and the nodes whose effective values change; nothing is saved until you confirm. A key the file leaves out is never touched; key: !reset deletes a value. Importing an unchanged export of this fleet changes nothing.
