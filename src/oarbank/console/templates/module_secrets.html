Secrets are write-only: once set, a value is never shown again, here or anywhere else; only that it is set, a fingerprint and when it changed. A stage's runner receives the secrets it lists, resolved for its node like a setting: the node's own value, else that of the highest-ranked group it is in that sets one, else the module's. Pair a secret with an egress allowlist naming only the service it is for.
